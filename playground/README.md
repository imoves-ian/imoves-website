# imoves playground

A private, password-protected experiment: the imoves.com sales site rebuilt as **one single page**. It is for trying ideas out. It is not the live site and not the development view, and it never feeds into either.

| | Live | Development | Playground |
| --- | --- | --- | --- |
| Branch | `production` | `main` | `playground` |
| Cloudflare Pages project | `imoves-site` / `imoves-website` | `imoves-site` | `imoves-playground` |
| Address | imoves.com | main.imoves-site.pages.dev | https://imoves-playground.pages.dev |
| Password | no | no | yes |

**Never merge the `playground` branch into `main`.** It starts from `main` at v0.27 but only adds files (`playground/` and `.github/workflows/deploy-playground.yml`); the live site's files are untouched.

## Signing in

The browser asks for a username and password. Username: `imoves`. The password is not stored in this repository (it is public); only a salted hash is, in `functions/_middleware.js`. Ian has the password.

Every response also carries `noindex, nofollow`, and `robots.txt` blocks all crawlers.

To change the password: `python3 playground/set-password.py "new-password"`, then commit and push `playground`. Or set an environment variable `PLAYGROUND_PASSWORD` on the `imoves-playground` Pages project in Cloudflare, which is accepted as well.

## What is on the page

One scrolling page with a sticky menu that jumps to each section: banner, how it works (with the showreel), Get Active / Get Focused / Be Calm, packages and prices, quality (afPE), the two showreels, reviews, book a demo, footer.

- **Packages and prices** is generated by `build.py` from the data block in `tools/versiond-compare.py`, the same data as the live comparison table, so prices cannot drift. A school-type switch (Infant / Junior / Primary) changes the price on every card; the full feature matrix is folded away under "Compare every feature". Do not hand-edit between the `GEN:packages` markers.
- Wording, reviews, images and videos come from the live homepage. Videos play from the same Cloudflare Stream account as the live site.
- Buttons go to the real platform checkout, sign-up and login, and the real demo booking link.
- Left out on purpose: Google Tag Manager (so playground visits do not count in the live analytics), the LeadConnector chat widget, and every other page of the site.

## Publishing

Push the `playground` branch. `.github/workflows/deploy-playground.yml` rebuilds the packages block and deploys `site/` plus `functions/` to `imoves-playground` with wrangler, using the repo's existing Cloudflare secrets. It creates the Pages project on its first run.
